# Pi Agent Desktop v0.8.3

发布日期：2026-08-26

## 新增

- **Provider 选择全量内置**：`pi-ai@0.84.3` 39 家 `MODELS.generated` 全部可在 `Models` 弹窗中可见，补齐 `ant-ling / baseten / nvidia / opencode / qwen-token-plan×3 / xiaomi / zai-coding-cn` 9 家图标（`@lobehub/icons`），`PROVIDER_ICONS` 现 39 映射
- **API Key 列表全量**：`GET /api/auth/all-providers` 改为以 `runtime.getProviders()` 为真源，不再因 `registry.getAll()` 零模型过滤导致 `openrouter-images` 等隐身，`AddProviderPicker` 网格自动出现未配置供应商
- **Custom 模板化**：`AddProviderPicker` 单卡 `OpenAI / Anthropic compatible` 拆为 4 模板：`OpenAI Compatible (openai-completions)` / `Anthropic Compatible (anthropic-messages)` / `OpenAI Responses (openai-responses)` / `Google Generative AI (google-generative-ai)`，按 `label/api/custom` 搜索过滤，`ModelsConfig.addCustomProvider(api)` 按所选 `api` 落盘

## 修复

- `qwen-token-plan` 三变体与 `zai-coding-cn` 之前渲染为无图标空白，现正确显示 `Qwen/ZAI` 图标

## 兼容性与已知限制

- Windows x64 安装包未进行代码签名，首次运行可能触发 SmartScreen 提示。
- `@lobehub/icons` 的传递依赖仍可能对 React 19 产生 peer warning。
- Electron 43.4.1 及其传递依赖的安全审计结果将在后续 Electron 大版本升级中单独处理。
