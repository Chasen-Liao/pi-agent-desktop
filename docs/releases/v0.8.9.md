# Pi Agent Desktop v0.8.9

发布日期：2026-09-23

## 新增

- **用量面板**：顶部状态栏展示会话输入 / 输出 Token、缓存读写和上下文占用；弹窗汇总会话用量、模型信息与上下文窗口容量。
- **上游额度查询**：显示 OpenAI Codex、DeepSeek、OpenRouter、Anthropic 的额度窗口和重置倒计时。数据通过本机可用的 provider 凭据查询；额度接口使用短期缓存并限制强制刷新频率。

## 修复

- **错误响应保持统一**：Agent 事件流初始化和长期记忆 API 失败时返回结构化 JSON 错误与 request ID；SQLite 忙锁耗尽重试时返回明确的 `503 ltm_busy`。
- **用量刷新竞态**：较早发出的查询不再覆盖更新的结果；改善 provider 匹配及凭据过期 / 不可用时的显示。

## 安全

- 更新 Next.js 与 `eslint-config-next` 至 16.3.6，并刷新受影响的传递依赖，修补上游 [Windows 服务端 RCE](https://github.com/vercel/next.js/security/advisories/GHSA-p293-qw3h-jr36)、[AVIF 图片优化 RCE](https://github.com/vercel/next.js/security/advisories/GHSA-2xp9-vwfh-vxw4) 和 [next/og RCE](https://github.com/vercel/next.js/security/advisories/GHSA-vcvr-r3jv-pc5j)；`npm audit` 当前报告 0 项漏洞。

## 兼容性与已知限制

- 上游额度依赖受支持 provider 的本机凭据和 provider 接口可用性；缺少凭据或额度接口不可用时，额度数据不会显示为有效结果。
- Windows / macOS / Linux 安装包均未代码签名。Windows 可能出现 SmartScreen 提示；macOS 可能出现 Gatekeeper 提示；Linux 自动更新经 `dpkg` / `apt` 安装未签名 `.deb`，需要 root 授权。
- 与终端 CLI 同时运行仍共享 `~/.pi/agent` 目录；同一 session 两端同时写入仍不受支持。
