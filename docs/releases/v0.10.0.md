# Pi Agent Desktop v0.10.0

发布日期：2026-10-11

## 升级

- **Pi SDK 升级至 1.1.0**：`@earendil-works/pi-ai`、`pi-coding-agent`、`pi-mcp` 从 0.99.1 跨大版本升到 1.1.0。依次跨越 1.0.0 / 1.0.x / 1.1.0，带来 Codemode 提示词降约 40% token、codemode 图像生成、MCP 项目级 override、`pi.registerToolRenderer()`、MCP OAuth 全链路可取消与请求超时、工具执行时长 `durationMs`、Claude Haiku 5.5 等上游改进。
- **漏洞修复随上游落地**：1.1.0 钉 `brace-expansion@5.0.12`，修复上游标记的 GHSA-q2hr-2g5m-vwhr 等漏洞。

## 修复

- **Azure Provider 改名适配**：上游 1.0.3 将 provider id 从 `azure-openai-responses` 改为 `azure`，模型配置界面的 Azure 条目图标 key 同步更新。使用旧 id 的既有 `auth.json` / `models.json` 需按上游说明改用 `azure`（环境变量 `AZURE_OPENAI_*` 不变）。

## 兼容性与已知限制

- 本次为跨 1.0 大版本升级，但经静态核实，本项目仅触达上述 UI 常量一处；其余破坏性变更（pi-agent-core 删 harness、pi-ai stream 类型、pi-tui Terminal、pi-mcp OAuth provider、`agent_settled.aborted` 字段）均未触及。详见 [docs/research/pi-core-upgrade-2026-10-11.md](../research/pi-core-upgrade-2026-10-11.md)。
- 未做正式三平台打包验证；Windows / macOS / Linux 安装包由 CI 产出。
- 与终端 CLI 同时运行仍共享 `~/.pi/agent` 目录；同一 session 两端同时写入仍不受支持。
