# Pi Agent Desktop v0.13.0

发布日期：2026-11-06

## 新增功能：统一设置中心与手动检查更新入口（#62）

本版本补齐了桌面端与 Web 工作台此前缺失的统一「设置」与「检查更新」入口，并打通了 Electron 主进程与渲染进程之间的手动更新检查、下载进度流与安装重启全链路。

- **多触点设置与更新入口**：
  - 侧边栏底部工具条新增「设置」按钮（与「模型」「技能」并列），有新版本可用或已下载时显示主题色圆点提示。
  - 右上角工作台菜单（`...`）新增「设置」与「检查更新」菜单项。
  - 全局支持 `Cmd/Ctrl + ,` 快捷键随时打开或关闭设置弹窗。
  - 系统托盘右键菜单新增「设置」与「检查更新」入口，点击后自动唤醒主窗口并定位到对应标签页。
- **三栏式统一设置中心（`SettingsModal`）**：
  - **常规**：集成浅色/深色外观切换、界面显示语言选择（跟随系统 / English / 简体中文），以及模型提供商、技能目录、扩展与 MCP 的快捷跳转卡片。
  - **智能体与工具**：集中配置新建会话的默认 Agent 模式（计划 / 询问 / 完全）、默认工具预设（关闭 / 默认 / 完整）及 Codemode 隔离脚本沙箱开关。
  - **关于与更新**：展示当前应用版本号、运行平台、软件更新状态卡片（支持手动检查更新、一键下载更新、实时下载进度条、下载完成后重启安装），以及 GitHub 仓库、版本发布日志与问题反馈外链。
- **Electron 更新状态机与 IPC 桥接**：
  - `electron/update-install-gate.ts` 新增纯函数更新状态机 `transitionUpdateStatus`（覆盖 `idle` / `checking` / `available` / `not-available` / `downloading` / `downloaded` / `error` / `unsupported` 八种状态），确保已下载完成状态不会被后续检查降级覆盖。
  - `electron/main.ts` 与 `electron/preload.ts` 新增 `get-app-info`、`get-update-status`、`check-for-updates`、`download-update` 与 `update-status` 广播通道，并增加并发重入守卫与交互式检查静默策略（用户在设置弹窗内手动点击检查更新时不重复弹出系统原生对话框）。
  - 新增 `GET /api/app-info` 端点，为非打包环境或浏览器模式提供版本号与仓库地址回退。

## 测试与工程

- 测试总数增至 731 项（731 通过，0 失败），新增覆盖 `SettingsModal` 表面结构、Electron IPC 更新通道注册与 `transitionUpdateStatus` 状态机演进。
- 补齐设置弹窗的 WAI-ARIA `tablist` / `tab` / `tabpanel` 语义以及 `prefers-reduced-motion` 动效降级保护。

## 兼容性与安装说明

- 安装包由 CI 构建，包含 Windows NSIS、macOS Universal DMG/ZIP、Linux DEB；各平台执行打包后的服务启动检查。
- Windows 安装包未代码签名，可能出现 SmartScreen 提示；macOS 安装包未签名、未公证，可能出现 Gatekeeper 提示。
- Linux `.deb` 未做包签名；自动更新通过 `dpkg` / `apt` 安装，需要 root 授权。下载完整性由 `latest-linux.yml` 的 SHA512 校验。
- 与终端 CLI 同时运行仍共享 `~/.pi/agent` 目录；同一 session 两端同时写入仍不受支持。
