# Pi Agent Desktop v0.11.0

发布日期：2026-10-16

## 侧边栏更新

- **文件夹式项目导航**：项目以可折叠的文件夹呈现，会话归属与分叉层级更清晰；优化行间距、选中状态、悬停操作和资源管理器区域。
- **三种项目排序方式**：默认按项目名称自然排序，可从顶部排序菜单切换为“最近活跃”或“手动排序”。最近活跃按项目内最新会话时间排列。
- **拖拽项目排序**：上下拖动项目文件夹即可调整顺序，放下后自动进入手动排序并保存。长列表支持边缘自动滚动，搜索期间暂停拖拽。
- **更连贯的交互动画**：完善文件夹展开收起、拖动预览、列表让位和落位反馈；支持键盘上下重排、Escape 取消，并遵循系统“减少动态效果”设置。
- 同步中英文界面文案，排序菜单仅保留名称、最近活跃和手动排序三个选项。

## 修复

- 重命名或删除会话失败时展示服务端返回的具体错误；响应缺失或无效时回退到通用错误提示。

## 兼容性与安装说明

- 拖拽仅调整项目文件夹的显示顺序，不移动磁盘目录，不改变项目内会话排序及分叉归属。
- 安装包由 CI 构建，包含 Windows NSIS、macOS Universal DMG/ZIP、Linux DEB；各平台执行打包后的服务启动检查。
- Windows 安装包未代码签名，可能出现 SmartScreen 提示；macOS 安装包未签名、未公证，可能出现 Gatekeeper 提示。
- Linux `.deb` 未做包签名；自动更新通过 `dpkg` / `apt` 安装，需要 root 授权。下载完整性由 `latest-linux.yml` 的 SHA512 校验。
- 本次依赖审计有 5 项 high、8 项 moderate、0 项 critical，属于既有 ESLint 与 Electron 打包工具链告警；本版本未执行跨主版本降级或强制依赖修复。
- 与终端 CLI 同时运行仍共享 `~/.pi/agent` 目录；同一 session 两端同时写入仍不受支持。
