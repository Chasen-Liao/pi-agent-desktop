# Pi Agent Desktop v0.12.0

发布日期：2026-10-22

## 仓库与代码清理

本版本以「清理 main 分支上过期的测试与代码」为主线，共 12 次提交、138 个文件、删除 1758 行、新增 4850 行（新增部分主要是新装的技能包、29 项测试与修复记录文档）。

- **移除死代码**：`lib/custom-path-selection.ts` 自原生目录选择器上线后已无任何生产引用，连同它的自测一并删除。
- **删除零引用导出**：`getRecentCwds`、`shortenCwd`（2026-10-16 侧边栏重构弃用）、`getQuitting`、`i18nServerFallback`。
- **清理恒真分支**：`MessageView` 底部的渲染守卫形如 `time || canFork || canNavigate || true`，条件恒为真，三个操作数已成噪音。
- **删除零引用依赖**：`@fontsource/inter`、`@fontsource/jetbrains-mono`（字体实际由 `next/font/google` 自托管）、`@electron/packager`（electron-builder 自带打包器），安装体积减少约 12MB。
- **清理一次性产物**：根目录临时文档、`.agents/` 下的历史 agent 任务记录、17 个已合并的本地分支与 14 个远端分支、1 个遗留 Git worktree（约 1.4GB）与旧版本安装包（约 995MB）。
- **修正陈述漂移**：文档中的顶层组件数（29→30）、顶层 hook 数（7→8）、Electron 辅助模块数（14→13）、API 路由数（38→39）、Next.js 与 Electron 版本号均已与代码对齐；Wave 1 / Wave 2 与长期记忆的设计与实施文档标注为「已落地」的历史文档。

## 安全

- **技能开关收敛到受校验的端点**。此前 `PATCH /api/skills` 会直接写入客户端指定的**任意文件路径**，没有任何白名单；同一语义的 `POST /api/extensions` 一直带有「目标必须位于允许的 skill 目录内」的校验，而前端恰好调用了未校验的那一个。现已统一：技能开关改走受校验端点，未校验的端点被移除。越界路径现在返回 **400** 并被拒绝，且目标文件不会被写入。

## 修复

- **`/statusline` 斜杠命令已真正接通**。该命令此前出现在斜杠菜单里却没有对应的处理分支，会作为普通消息发给模型，用户看到的是模型的回复而不是状态栏；配套的状态接口虽然实现完整却从未被前端调用。现在命令会拉取工作区状态，在对话区给出符号化摘要，并在状态栏显示分支名、领先/落后提交数与脏文件计数；再次执行该命令即隐藏该区域。
- **补齐 409 信任握手的行为测试**。项目信任是一条安全边界，此前整条链路（重试上限、取消返回 499、信任决策的五个分支、会话创建时的 409 载荷）没有任何行为测试，仅有的相关断言只检查「文件长度大于 50 字符」。本版本新增 20 项测试覆盖这些路径，并做了变异验证。

## 测试与工程

- 测试总数从 693 增至 729，全部通过；新增覆盖信任握手（会话创建与已有会话两条路径）、状态接口、技能越界写入与斜杠命令分发。
- 命令分发改为受类型约束的映射表：**菜单里新增命令却没有 handler 会直接编译失败**，从根上杜绝「命令穿透给模型」。
- 修正了路由层无法编写单测的工程问题：39 条 API 路由中有 19 条使用裸 `next/server`、24 条使用 `@/` 别名，测试运行器无法解析，因此此前写不了路由测试；现改为可解析写法（12 条已符合，其中 6 条已有测试），并将该约定写入 `AGENTS.md`。
- 修正本地 lint 噪音：本地构建产物目录此前会被 ESLint 扫描，导致本地报出 15 个 CI 永远不会看到的错误；现为 0 错误。

## 兼容性与安装说明

- 安装包由 CI 构建，包含 Windows NSIS、macOS Universal DMG/ZIP、Linux DEB；各平台执行打包后的服务启动检查。
- Windows 安装包未代码签名，可能出现 SmartScreen 提示；macOS 安装包未签名、未公证，可能出现 Gatekeeper 提示。
- Linux `.deb` 未做包签名；自动更新通过 `dpkg` / `apt` 安装，需要 root 授权。下载完整性由 `latest-linux.yml` 的 SHA512 校验。
- 本次依赖审计有 5 项 high、8 项 moderate、0 项 critical，与 v0.11.0 持平，全部属于既有 ESLint 与 electron-builder 打包工具链告警；本版本未执行跨主版本降级或强制依赖修复。
- 移除的三个依赖均无源码引用，不影响运行时行为；字体仍由 `next/font/google` 在构建期自托管。
- 与终端 CLI 同时运行仍共享 `~/.pi/agent` 目录；同一 session 两端同时写入仍不受支持。

相关改动：仓库清理与三个已记录问题的修复，详见仓库内 `docs/fixed-issues-2026-10-22.md`。
