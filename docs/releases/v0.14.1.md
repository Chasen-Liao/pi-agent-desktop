# Pi Agent Desktop v0.14.1

发布日期：2026-11-23

## 修复：自动更新安装失败后可重试（#68）

v0.14.0 的自动更新在安装阶段缺少失败后的可重试路径：Windows 在确认安装器能启动之前就进入退出流程，macOS 每次失败的 `quitAndInstall` 都会在原生 updater 上留下常驻监听器，失败一次后只能重新检查更新。本版本把两个安装入口统一为可重试路径：

- **Windows 先启动安装器，再退出应用**：新增 `electron/update-windows-installer.ts`（`launchWindowsInstaller`），直接用 `spawn` 启动 electron-updater 已校验的 NSIS 安装器（`--updated --force-run`，detached），等 `spawn` 事件确认进程启动后才执行 `app.quit()`。安装器启动失败（例如路径缺失导致 `ENOENT`）会 reject，应用保持运行，更新状态仍为「已下载」。
- **macOS 先暂存，再调用系统安装**：新增 `electron/update-mac-staging.ts`（`stageMacUpdate`），在 `MacUpdater.quitAndInstall()` 之前先用 Electron 原生 `autoUpdater` 等待 `update-downloaded`，成功或失败后都会移除临时监听器，避免失败重试时监听器累积；`update-not-available` 视为可重试失败。`macUpdateStaged` 记录暂存结果，再次重试不会重复暂存。
- **安装失败不再清空已下载状态**：`electron/update-install-gate.ts` 的 `error` 转换在存在 `downloadedVersion` 时把状态保留为 `downloaded`，只更新错误消息；设置弹窗「关于」页在已下载状态展示「更新安装失败，请重试。」（新增 `settings.about.installError`，中英文双语），IPC `quitAndInstall` 返回 `ok: false` 或抛异常时同样显示该提示。
- **「稍后」真正延后安装**：设置 `autoUpdater.autoInstallOnAppQuit = false`，用户选择稍后后，正常退出应用不会再自动安装。
- **统一入口与单飞保护**：IPC `quit-and-install` 与下载完成时的「立即重启」对话框共用 `runQuitAndInstall()`，通过 `installInFlight` 防止重复安装；安装阶段的错误会复位安装与退出状态，macOS 暂存期间的 updater 错误交由安装流程统一处理，不再重复广播。

## 测试与工程

- 本地运行通过：`npm run lint`（0 errors，9 条既有 warning）、`npx tsc --noEmit`、`npx tsc -p electron/tsconfig.json --noEmit`、`npm test`（749 项测试：747 通过，2 项 Windows 环境跳过 POSIX 路径校验，0 失败）、`npm run check:landing-orb`。
- 新增 `electron/update-mac-staging.test.ts` 与 `electron/update-windows-installer.test.ts`；`electron/update-install-gate.test.ts` 补充「安装失败保留已下载版本以便重试」用例；`electron/main-update-gate.test.ts` 改为校验两个安装入口共用受门禁的单飞路径。
- 仓库索引切换为 AOCI（`aoci.txt` / `aoci.code.txt` / `.aoci/`），并移除未使用的 skill 目录；不涉及桌面运行时行为。

## 兼容性与安装说明

- 发布时由 CI 构建安装包，包含 Windows NSIS、macOS Universal DMG/ZIP、Linux DEB，各平台执行打包后的服务启动检查。
- Windows 安装包未代码签名，可能出现 SmartScreen 提示；macOS 安装包未签名、未公证，可能出现 Gatekeeper 提示。
- Linux `.deb` 未做包签名；自动更新通过 `dpkg` / `apt` 安装，需要 root 授权。下载完整性由 `latest-linux.yml` 的 SHA512 校验。
- 与终端 CLI 同时运行仍共享 `~/.pi/agent` 目录；同一 session 两端同时写入仍不受支持。
