# Pi Agent Desktop v0.9.0

发布日期：2026-10-01

## 新增

- **Pi 原生 MCP**：核心升级至 0.99.1，桌面会话直接使用官方 MCP 和工具搜索扩展。配置 UI 支持 stdio、Streamable HTTP、HTTP headers、启用/禁用和工具暴露方式；连接测试执行真实协议握手及工具发现。
- **Codemode 管理**：在“工作台菜单 → 扩展与 MCP → Codemode”开启或关闭，并查看模式说明与使用示例。Pi 可在隔离的 JavaScript 运行环境中组合工具调用、筛选和合并结果；普通工具调用仍可用。偏好持久保存，运行中的任务结束后应用。

## 修复

- Codemode 内的工具调用继续遵守 Ask 确认、Plan 和禁用工具约束。
- 保留原生工具搜索激活结果，后续消息不再清除已发现的 MCP 工具；损坏的单个配置条目不再阻断同文件里的合法服务。
- MCP 配置更新在下一条消息前重载，关闭会话时释放原生 MCP 连接。兼容旧桌面配置字段，保留已有 OAuth 等高级配置。
- 使用官方会话投影处理 `context_edit`，避免编辑或省略消息后历史来源 ID 错位。
- 修复 HTML 导出深层依赖导致的 worker/WASM 构建失败，并在 standalone 检查中验证真实 HTML 导出。
- 修复 shader 变量 lint 和 usage 路由额外导出导致的 CI 阻塞。

## 安全

- 更新 Electron 至 43.7.7，并刷新 brace-expansion、fast-uri、DOMPurify、undici 等兼容范围内的依赖修复版本；发布前 `npm audit` 报告 0 项漏洞。

## 兼容性与已知限制

- Pi 原生 MCP 支持 stdio 和 Streamable HTTP，旧 SSE 端点需要手动迁移，不能直接当作 HTTP 使用。项目 MCP 配置需要项目信任。
- MCP UI 显示配置状态；当前会话的连接详情和 OAuth 认证由原生 `/mcp` 命令管理。
- Windows / macOS / Linux 安装包均未代码签名。Windows 可能出现 SmartScreen 提示；macOS 可能出现 Gatekeeper 提示；Linux 自动更新经 `dpkg` / `apt` 安装未签名 `.deb`，需要 root 授权。
- 与终端 CLI 同时运行仍共享 `~/.pi/agent` 目录；同一 session 两端同时写入仍不受支持。
