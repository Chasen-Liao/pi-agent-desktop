# Pi Agent Desktop v0.14.0

发布日期：2026-11-09

## 新增功能：窗口关闭行为、流式滚动控制与右键编辑菜单（#64 / #66）

本版本围绕桌面端日常使用体验新增三项交互与窗口偏好设置，均可在「设置 → 常规 → 窗口与对话」或桌面上下文菜单中直接使用：

- **关闭按钮行为可选（最小化到托盘 / 退出程序）**：
  - 在设置弹窗新增「关闭按钮行为」切换项（`tray` / `quit`，默认 `tray`），持久化保存至 `~/.pi/agent/desktop-settings.json` 并通过 `set-close-action` IPC 实时同步至 Electron 主进程。
  - 新增 `electron/window-options.ts`，在主进程内存状态尚未初始化时自动回退读取磁盘配置（`readCloseActionFromDisk`），路径解析与 Pi SDK `getAgentDir()` 保持一致（支持 `PI_CODING_AGENT_DIR`、`~` 及 `file://` URL）；选择「退出程序」后点击关闭按钮将标记退出并调用 `app.quit()` 清理后台服务进程。
- **回答生成时自动滚动开关（`followStreaming`）**：
  - 在设置弹窗新增「回答生成时自动滚动」开关（默认开启）。
  - 新增 `hooks/agent-session/chat-scroll-policy.ts`（`shouldFollowStreamingUpdate`、`shouldFollowAgentSettle`）控制流式更新与回答结束时的自动滚底；关闭后仅在用户发送消息时滚动，方便用户从回答开头稳定阅读长回复。
- **原生右键上下文菜单（`installContextMenu`）**：
  - 为 Electron 主窗口注册 `webContents` `context-menu` 事件，提供标准的剪切、复制、粘贴与全选操作（按 `editFlags` 动态启用），并在右键链接时附带中英文自适应的「复制链接地址 / Copy Link Address」菜单项。

## 兼容性与安装说明

- 安装包由 CI 构建，包含 Windows NSIS、macOS Universal DMG/ZIP、Linux DEB；各平台执行打包后的服务启动检查。
- Windows 安装包未代码签名，可能出现 SmartScreen 提示；macOS 安装包未签名、未公证，可能出现 Gatekeeper 提示。
- Linux `.deb` 未做包签名；自动更新通过 `dpkg` / `apt` 安装，需要 root 授权。下载完整性由 `latest-linux.yml` 的 SHA512 校验。
- 与终端 CLI 同时运行仍共享 `~/.pi/agent` 目录；同一 session 两端同时写入仍不受支持。
