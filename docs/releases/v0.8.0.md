# Pi Agent Desktop v0.8.0

发布日期：2026-08-25

## 亮点

- 重设计桌面工作区：更紧凑的工具栏、消息输入区和 Apple 风格材质层级。
- 新增液态思考球：WebGPU 优先，Canvas 自动降级，并遵守 reduced-motion 设置。
- 新增可重排 Follow-up Queue：Agent 运行中按 Enter 立即 steer，按 Alt+Enter 排队；支持拖拽、按钮和 Alt+方向键调整顺序。
- Steer 消息显示待投递状态，服务端确认后与会话消息对齐。

## 运行时与依赖

- Pi SDK：`@earendil-works/pi-ai` / `pi-coding-agent` `0.84.3`。
- Next.js / eslint-config-next：`16.3.2`。
- electron-updater：`6.8.9`；electron-builder：`26.15.3`；@electron/packager：`20.3.0`。
- 修复可安全升级的 npm 依赖漏洞；Electron 仍保持 `36.9.5`，避免在本次发布中引入跨 8 个大版本的桌面运行时回归。

## 兼容性与已知限制

- Windows x64 安装包未进行代码签名，首次运行可能触发 SmartScreen 提示。
- `@lobehub/icons` 的传递依赖仍对 React 19 产生 peer warning；当前品牌 SVG 深度导入已通过类型检查与测试。
- 完整 `npm audit` 仍报告 Electron 36 与其 `extract-zip` 的 2 项 high；升级 Electron 44 将作为独立任务处理。
- Next.js 16.3 仍兼容当前 `middleware.ts`，但已提示未来迁移到 `proxy.ts`。

## 验证

- Web 与 Electron TypeScript 类型检查通过。
- 单元测试、Lint、Electron updater 依赖检查通过。
- Next.js 开发模式健康检查返回 200，恶意 Origin 请求返回 403。
- Windows NSIS 安装包在发布前由 `npm run dist` 重新构建并核对产物元数据。
