# Pi Agent Desktop v0.8.4

发布日期：2026-08-28

## 新增

- **拖拽上传文件**：将任意文件拖入聊天窗口即以 `@path` mention 形式插入，Agent 可直接读取该文件（#18）

## 修复

- **Provider API Key 持久化**：`Models` 弹窗保存的 API Key 此前只写入内存 override（随每次请求的临时 runtime 丢弃），从未落盘 `auth.json`，导致新配置的 provider 永远显示"未配置"、不出现在列表中。现改走 SDK `login(api_key)` 持久化路径，保存后立即可见、重启仍生效；Disconnect 同步真正删除已存凭据（#21）
- **安装包目录页提示**：NSIS 安装器切换盘符（C→D）时路径框只显示盘符根目录，易误以为默认文件夹丢失而手动输入（手动输入可能造成嵌套目录）。现目录页顶部显示双语提示，说明 `Pi Agent Desktop` 子文件夹会自动创建（#19）
- **构建修复**：`build/installer.nsh` 增加 UTF-8 BOM。无 BOM 时 makensis 按系统 ANSI 代码页解析 include，文件中的 em-dash 在 zh-CN/GBK 机器上会触发 `Bad text encoding` 编译失败

## 兼容性与已知限制

- Windows x64 安装包未进行代码签名，首次运行可能触发 SmartScreen 提示。
- 仅环境变量认证的 provider（如 GitHub Copilot）不支持在弹窗中保存 API Key，保存时将返回明确错误。
